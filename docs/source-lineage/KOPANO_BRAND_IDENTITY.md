# Kopano Brand Identity

## Name & Etymology
**Kopano** — from Sesotho and Setswana: “gathering” or “meeting together.”

## Ecosystem Naming
| Product | Name | Role |
|---------|------|------|
| Core framework | **Kopano Context** | Orchestration engine and primary ecosystem framework |
| Terminal interface | **Kopano CLI** | Developer terminal interface |
| React GUI | **Kopano Studio** | Agent/runtime visualization dashboard |
| Multi-agent network | **Kopano Mesh** | Parallel agent coordination layer |
| Product studio | **Kopano Labs** | Experiment gallery for South African impact tools |
| Collaborative execution | **Kopano Forge** | Canvas/workflow execution tool |
| Coding acceleration | **Kopano Code** | Coding and craft-learning tool |
| Trust layer | **Kopano SafeSkill** | Audit-twice verification layer |
| Internal engine | **kopano-core** | Internal orchestration engine |

## Brand Voice
Highly technical, direct, unpretentious, transparent about system behavior, and hostile to vague claims that cannot be demonstrated.

## Taglines
- Technical: **Orchestrating intelligence. Unifying context.**
- Security: **The trust layer for multi-agent AI.**
- Action: **Connect the context. Let the agents build.**

## Core Palette
| Token | Name | Hex | Usage |
|-------|------|-----|-------|
| `--color-bg` | Karoo Night | `#0D1117` | Primary dark background |
| `--color-brand` | Savanna Gold | `#F5A623` | Brand/action accent |
| `--color-success` | Terminal Mint | `#00E676` | Verified/pass states |
| `--color-text` | Chalk Dust | `#E2E8F0` | Body text |

## Typography
- Headings / brand: Space Grotesk or Fira Code
- Body / documentation: Inter or Geist

## Logo Concepts
- **Indaba Nodes:** connected AI nodes around a central moderation point.
- **Secure Weave:** woven code brackets as context + cultural metaphor.
- **Terminal Shield:** terminal prompt inside a shield for audit/security emphasis.

## Website implementation consequence
The website should read like a technical product studio, not a generic agency landing page. The visual system should remain dark-first, evidence-oriented, developer-readable, and South African without collapsing into decorative cultural motifs.
