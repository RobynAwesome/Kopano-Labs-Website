# RobynAwesome Profile Repository Audit

Audited repository: `RobynAwesome/RobynAwesome`  
Audit date: 2026-08-08

## Useful signals carried into the website rebuild

- Kopano Labs is the ecosystem umbrella, not a single project card.
- Public identity is grounded in South African constraints and real-world validation.
- Sovereign / offline-first architecture is a recurring engineering direction.
- Active systems should be connected to visible evidence and production state.
- The GitHub Project Memory Registry is the correct durable place to record canonical repository boundaries.

## Problems not copied into the website

- stale unemployment percentages presented as identity copy;
- malformed Markdown/table fragments in the stack section;
- absolute technology claims such as “exclusively build” that are too brittle for a public institutional site;
- role descriptions for AI tools that read as internal workflow notes rather than durable public product information;
- portfolio links that point to old deployment surfaces instead of canonical product domains.

## Governance repair performed

`GITHUB_PROJECT_MEMORY.md` was updated to register `RobynAwesome/Kopano-Labs-Website` as the dedicated source for KopanoLabs.com and to explicitly exclude the Money Manager fork and retired Cars4Mars landing-page repository from the website production dependency graph.
