## Pattern learning used

Only broad, non-copied interaction principles were carried forward:

- spatial state should respond to user focus;
- motion should reveal hierarchy;
- interfaces should feel navigable rather than brochure-like;
- low-power/mobile fallbacks must preserve meaning.

The actual implementation remains original and builds on the existing first-party Kopano Three.js/R3F/Framer Motion runtime.

## Security boundary

The breach visual is an educational trust-boundary model. It deliberately does not contain secrets, credential layout, private network addresses, exploitation steps or a claim of penetration-test evidence.
